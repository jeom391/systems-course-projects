# Systems Course Projects

Selected course projects related to systems programming, compilers, and concurrency.

## Projects

### [SIC Assembler](./sic-xe-assembler)
Implemented an assembler for the SIC architecture, including symbol table management, instruction encoding, and object code generation.

### [miniC Compiler](./minic-compiler)
Implemented core components of a compiler for a miniC-like language, including lexical analysis, parsing, semantic analysis, and code generation.

### [Lock Implementation and Analysis](./lock-implementation-analysis)
Implemented and analyzed synchronization mechanisms under concurrent execution scenarios.

## Topics

- Systems Programming
- Assembly and Object Code Generation
- Compiler Construction
- Concurrency and Synchronization
- Low-level Debugging
